# A1 OQI Timeline Manager


## Setup
To use the timeline manager, pull the repository from Github and run the following command to open the manager
´
Add the following information in Git Settings:

- GitHub Personal Access Token: Add the token here.
- Repository Owner: OpenQuantumInstitute
- Repository Name: A1-timeline
- File Path: timeline-data.json
- Branch: Master

You can now pull and push from Github, as well as sync the subscription calendar with the button "Sync calendar to GitHub"


# Calendar subscription
Get the calendar including all tasks and evaluation period, by subscribing to the following url in your calendar application:
https://raw.githubusercontent.com/OpenQuantumInstitute/A1-timeline/master/timeline.ics

Go to the browser version of outlook.
Click on calendar, then click on add to calendar and the "Subscribe from Web" - put the calendar url as provided.
